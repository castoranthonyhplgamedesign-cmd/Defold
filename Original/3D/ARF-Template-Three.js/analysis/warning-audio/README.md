# Original conveyor warning cue

Revised 2026-10-30 after the user rejected the first two-note cue and supplied `OnWarning.wav`. Its measured waveform has two strong bursts around 0.12-0.43 seconds, low-frequency components around 78/156 Hz with strong 312/624 Hz harmonics, and a quieter tail through its 0.96-second duration. See `onwarning-analysis.json`. These are waveform/spectrum measurements, not a listening audition.

`scripts/prepare-warning.mjs` now synthesizes a low double-buzzer from scratch: two 98 Hz bursts with strong upper harmonics for small speakers, slight downward pitch movement, soft saturation and a short reflection tail. Pitch and envelope differ from the reference; no reference samples are used. Source duration: 460 ms. Output: `src/assets/audio/warning-pulse.mp3`, mono 44.1 kHz, 96 kbps, 6,314 bytes. Both supplied reference files remain unchanged. The rejected sound/generator are archived here, outside shipping bundles.

The asset is peak-scaled to 0.4 before MP3 encoding; runtime gain is 0.22. This leaves headroom for cannon SFX and BGM. Exact decoded measurements and standalone build size are in `analysis/evidence/warning-build.json`. This is measured level balancing, not an audition of the mix.

The warning uses two pre-created HTMLAudioElements in the existing pool. Session phase drives both the visual crest and the sound request: 1.1-second pulses, or the existing 0.3-second alert pulse. The original opacity range and reduced-motion static overlay are preserved. Reduced motion does not disable the warning sound. Phase freezes while gameplay is paused. The warning is silent before interaction, stops below 95% fullness and at every ending, and does not replay missed cues on resume.

Validation: the preceding implementation passed 149 tests and typecheck; this revision changes only the asset generator, MP3 and duration assertion. Fresh muted Chrome checks observed three real audible-mode warning starts, normal pulse cadence, hidden-state cancellation, resumed future pulses, landscape/reduced-motion playback and cancellation below the threshold. No page errors. The 460 ms duration fits two voices even at the fastest 300 ms pulse cadence. Browser evidence is `analysis/evidence/warning-browser.json`; this is not physical speaker evidence. Target Safari/iPhone/iPad/Android and official hosts remain unverified.

Standalone build is under the 4 MB target, at `analysis/build/warning-preview/index.html`. Network delivery files in `dist/` were subsequently rebuilt on user request: 32 packages for `3clicks`, `10clicks`, `60seconds`, and `full`; 90 seconds excluded. Every package contains the exact revised MP3. Largest HTML: 3,893,484 bytes. The packaged 60-second AppLovin smoke test passed with 37 prepared voices. See `analysis/evidence/warning-delivery-build.json`. Refresh the dev page to test, or listen directly to the exported MP3. Audio character, final loudness and phone-speaker suitability need user audition.
