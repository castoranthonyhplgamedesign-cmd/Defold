# Milestone 2 — arrow launch and conveyor

Status: implemented, 2026-10-22. Stop for developer review before cannon targeting/ammo.

**Developer-requested feedback update:** the head-only reference nudge below has been superseded by the colleague template's whole-arrow contact, cascading shake and route reversal. See [blocked-feedback.md](blocked-feedback.md). Historical nudge measurements below describe the earlier implementation.

## Review

Open `../dist/index.html`, or run `npm.cmd run dev`. Tap any segment of an arrow. A blocked arrow nudges its head and returns; a free arrow launches, straightens its corners and feeds the conveyor. Multiple arrows can launch independently. Reload to reset. Cannons remain stationary visual placeholders and do not fire yet. There is intentionally no lose state when the conveyor fills.

## Implementation

- `src/core/path.ts`: engine-independent polygon resampling, sampled progress/position, direction and entry selection.
- `src/core/simulation.ts`: validated board state, open-front checks, launch admission, head/tail transit, group flags, conveyor movement, removal and blocked feedback. No Three, DOM, audio or host imports.
- `src/render/board.ts`: dynamic instanced board/conveyor meshes and source-sized analytical collider picking. Stable arrow IDs are independent of mesh instances.
- `src/input/taps.ts`: one native input family, accepted identifier ownership, tap-release activation, drag rejection, outside release, cancel, blur, resize and disposal. Touch strategy includes iPadOS desktop mode.
- `src/main.ts`, `src/render/scene.ts`: wiring, one animation frame chain, resize without canvas recreation, document/context pause and resource cleanup.
- `src/data/path.json`: 12 extracted world control points; regenerated by asset preparation. No editor integration or global configuration API.

## Intentional adaptations / unresolved fidelity

**Inferred implementation choices:** 1/120-second deterministic substeps; browser frame contribution capped at 0.1 seconds; document/context hide pauses active time rather than using Date.now for the fallback. Input movement tolerance is 10 CSS pixels; release must still select the originally pressed arrow. Genuine cancel never launches. Repeated blocked taps restart one nudge rather than layering source tweens.

Conveyor updates run before transit per substep. Once a tail joins, path state owns its pose; the source also writes following poses to already-entered tails depending on component update order. Group flags clear immediately when all segments have entered. Exact source component ordering and visual interpolation remain **Unknown**. Congested forced insertion may overlap blocks, as implied by the source; no invented queue or pushback was added.

The 79-arrow/406-cell candidate remains **Inferred** from declared serialized array lengths. Its uniqueness/contiguity is tested; exact Cocos runtime expansion remains unverified. Neither full-board solvability nor shooter ammo balance is claimed.
