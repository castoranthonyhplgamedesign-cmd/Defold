# Level files

- `overload-level.arrow-flow.json`: current playable layout, imported by `vite.config.ts`. Runtime cannon queues and hint order come from `src/data/overloadCannons.ts`.
- `conveyor_overload_v2.arrow-flow.json`: supplied layout revision used to prepare the current level.
- `untitled-level.arrow-flow.json`: earlier supplied level, retained for comparison and editor checks.
- `untitled-level.fixed.arrow-flow.json`: historical adjustment, superseded by the original-grid mockup requirements.

All four files were moved without changing their contents. Use the editor's Open button to load one. Browser-local editor drafts were not reset. Example levels remain under `examples/levels/`.
