# Wide-U Port Asset Inventory

Current Babylon playable source assets live in `src/assets/`.

## Rendered Models

- Board base, border, 1x1 tile, 1x2 tile, and gate meshes are embedded in `src/generated/wideUModels.ts`.
- Runtime materials are simplified mobile-friendly Babylon `StandardMaterial` instances using the final sampled color palette in `src/data/colors.ts`.

## UI

- `app_icon.png`
- `play_now.png`
- `hand_pointer.png`
- End card reuses `app_icon.png` and `play_now.png`.

## Audio

- Source WAVs are retained for traceability.
- Runtime imports use compressed mono WAV files generated by `npm run compress:audio`:
  - `bgm_compressed.wav`
  - `crumple_compressed.wav`
  - `drag_compressed.wav`
  - `drop_compressed.wav`
