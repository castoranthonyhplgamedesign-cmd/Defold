# Unblock Puzzlebox — Defold HTML5 port

Baseline: `Original/2D/2026.10.14-CCS-MIP-unblock_puzzlebox`, `main` at `be16ff7d7afada777f1160be16df37485adac21b`.

This project renders through Defold GUI and implements gameplay rules, timing, input interpretation, progression and end states in Lua. A browser bridge retains the exact Matter solver bundled in Phaser 3.90. Phaser's renderer and scene runtime are not included in the translated build. This is an HTML5 target; the Matter bridge does not support native Defold builds.

## Build and local publication

Requirements: installed Defold editor under `%USERPROFILE%/Documents/Defold` (or `DEFOLD_HOME`), Node, Python with Pillow, Git.

The reference staging copy under `tools/reference` is ignored. To recreate it, copy the original repository contents there, excluding `.git` and `node_modules`. Never install dependencies or generate builds in `Original`.

```powershell
python scripts/stage_reference.py
npm.cmd ci
python scripts/build_local.py --assets
python scripts/serve_local.py
```

The build uses the JDK and builder included with the installed Defold editor. `--assets` regenerates converted PNGs; omit it for code-only rebuilds. Publication writes to `local-publish/` and serves **only 127.0.0.1:8171**. There is no cloud deployment or Git remote push.

Open `http://127.0.0.1:8171/Ring%20Sort/index.html?variant=60sec` (bundle directory may be sanitized by Defold; see `qa/build.json`). Variants: `3clk`, `10clk`, `60sec`. `hud=1` shows the source's optional restart/objective HUD; default delivery layout shows NEXT only.

All store redirects are recorded and suppressed on loopback, including automatic end redirects. No external store window opens during local play or QA. Off loopback, the adapter contains the source SDK priority routes, but no network-certified ad export is claimed.

## Test and compare

Start a read-only working copy of the source with:

```powershell
node node_modules/vite/bin/vite.js tools/reference --host 127.0.0.1 --port 8172
node scripts/compare.mjs
node scripts/solver-parity.mjs
node scripts/qa.mjs
node scripts/viewport_qa.mjs
```

The QA script uses muted headless Chrome. `qa=1` on loopback enables snapshots and controlled fixtures for end-state/rule testing. Those fixtures are distinct from normal pointer-driven gameplay. Screenshots, machine-readable test outcomes and the QA report are stored under `qa/`.

## Source mapping

| Source | Defold implementation |
|---|---|
| `constants.ts` | `modules/constants.lua`, generated by `scripts/prepare.mjs` |
| `Board.ts`, `Ball.ts` | `modules/board.lua`, `modules/view.lua` |
| `GameScene.ts`, `Launcher.ts`, `iteration.ts` | `main/game.gui_script` |
| `Hand.ts`, `Hud.ts`, `Danger.ts`, `WinFx.ts`, `cta.ts` | `modules/view.lua`, orchestration in GUI script |
| Phaser Matter implementation | `web/physics.js`, bundled solver from pinned Phaser dependency |
| `pile.ts`, `rng.ts` | traceable derived `web/pile.ts`, preserving JavaScript integer RNG behavior |
| `audio.ts`, browser input and network lifecycle | `web/host.js` |
| Original WebP/font/audio assets | `assets/`, `web/audio/`; detailed `docs/ASSET_MANIFEST.json` |

Read `docs/WORK_LOG.md` and `qa/REPORT.md` for validation status and remaining limitations. Compilation alone does not establish visual/audio parity or client acceptance.

## Single HTML delivery

The final standalone file is `D:\allproject\defold\output\Ring Sort.html`. It contains its engine, archives, audio, icons and scripts and can run directly from disk without sibling files. Each build runs `scripts/package_single_html.py`, overwriting the same file. The obsolete `Sinonimus.html` is removed; unrelated game exports are preserved. To package an existing local build: `python scripts/package_single_html.py`. Verify in an isolated folder with network disabled: `node scripts/single_html_qa.mjs`.
